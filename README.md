## About
A simple web app where you type text on the left and see slides on the right. It is made with HTML, CSS and JavaScript only.

## How to Use
- Write your slides in the text box.
- Put `---` on its own line to start a new slide.
- Use `#`, `##` or `###` at the start of a line to make headings.
- Click **Left** and **Right** to move between slides.
- Click **Save** to keep your slides in the browser.
- Click **Present** to show the slides in full screen.

## Files
- `index.html` – page structure
- `style.css` – colors and layout
- `script.js` – slide logic

## Run
Keep all three files in one folder and open `index.html` in a browser.
